# EG4S20BG256 暑期项目后续工作操作指南

适用对象：电气工程专业、第一次使用 Altium Designer 的学生。

> 重要结论：当前工程是结构化草稿，不是可直接制板的成品。请严格按照“原理图 → ERC → 封装 → PCB → DRC → 输出”的顺序工作。不要在原理图尚未连通时开始正式布线，否则后面改一个网络，PCB 就要大面积返工。

---

## 一、你最终要交付什么

完整项目至少应包含：

1. 一个能正常打开的 `EG4S20_SummerProject.PrjPcb` 工程。
2. 五张原理图：连接器、FPGA/时钟/Flash、USB-UART/JTAG、用户 IO、电源。
3. 一张正式 PCB：板框正确、器件全部在板内、网络同步、完成布局布线和铺铜。
4. ERC 和 DRC 检查结果；所有 Error 清零，Warning 逐条确认。
5. 原理图 PDF、BOM、Gerber X2、NC Drill，以及必要的装配说明。

当前目录中的 `EG4S20_CoreBoard.PcbDoc` 和 `EG4S20_CoreBoard_recovery.PcbDoc` 只作为草稿/恢复文件。正式 PCB 建议在原理图完成后重新生成，避免继续修补现有的三角形板框和离散焊盘阵列。

## 二、开始前先做备份

### 2.1 关闭活动命令

每次保存前先按两次 `Esc`。如果弹出 “A command is currently active”，选择 `No`，再按两次 `Esc` 后保存。

### 2.2 建立日期备份

1. 退出 Altium Designer。
2. 在文件资源管理器中复制整个 `EG4S20_SummerProject` 文件夹。
3. 将副本命名为 `EG4S20_SummerProject_backup_2026-07-06`。
4. 后续每天开始工作前再复制一次，只保留最近 3～5 个版本即可。

不要只备份 `.PrjPcb`；它只是工程索引，真正内容在 `.SchDoc` 和 `.PcbDoc` 中。

---

## 三、第一次打开工程

1. 启动 Altium Designer。
2. 选择 `File → Open Project`。
3. 打开 `EG4S20_SummerProject.PrjPcb`。
4. 左侧 `Projects` 面板应显示五张 `.SchDoc` 和一张 `.PcbDoc`。
5. 如果看不到 `Projects` 面板：点击右下角 `Panels → Projects`。
6. 双击某个文档即可打开；标签右侧出现 `*` 表示有修改尚未保存。
7. 使用 `Ctrl+S` 保存当前文档，使用 `File → Save All` 保存全部文档。

### 3.1 必须掌握的鼠标和快捷键

- 鼠标滚轮：缩放视图。
- 按住鼠标右键拖动：平移视图。
- `Ctrl+Z`：撤销。
- `Delete`：删除选中对象。
- `Esc`：取消当前放置、布线或移动命令。
- `Space`：移动器件时旋转 90°。
- `V` 后按 `F`：缩放到显示全部对象。
- PCB 中按 `2`：二维布局模式；按 `3`：三维模式。

操作失败时先按两次 `Esc`，再重新开始，不要连续乱点。

## 四、第一阶段：把原理图真正画完整

### 4.1 什么叫“真正连接”

当前页面上的很多网络标签只是文字，未必已经连接到器件引脚。有效连接必须满足以下任意一种情况：

- 绿色导线端点准确吸附到器件引脚端点；
- Net Label 的连接点准确落在绿色导线上；
- Power Port 的连接点准确落在导线上；
- 两根导线交叉处需要连接时，交点必须显示 Junction；不需要连接时不能有 Junction。

同名 Net Label 会被 Altium 视为同一网络。例如不同位置都使用 `UART_TXD_D12`，它们在电气上相连。网络名必须完全一致，空格、加号、大小写和下划线不要随意变化。

### 4.2 放置、移动和连线

1. 在原理图页面空白处单击，确保当前页面获得焦点。
2. 放置器件：`Place → Part`，在 Components 面板中搜索器件名。
3. 移动器件：将鼠标放在器件主体上，按住左键拖动；移动时按 `Space` 旋转。
4. 放置导线：`Place → Wire`，先点击引脚端点，再点击转角，最后点击目标引脚；右键结束。
5. 放置网络标签：`Place → Net Label`，输入名称，将标签连接点放到导线上。
6. 放置电源端口：`Place → Power Port`，选择 `GND`、`3V3`、`1V2` 等名称。
7. 双击器件打开 Properties，检查 `Designator`、`Comment` 和 `Footprint`。
8. 每完成一个小电路立即 `Ctrl+S`。

### 4.3 按页面完成，不要跨页乱画

#### 页面 1：`01_Connectors.SchDoc`

目标：画出 USB 接口和扩展排针，并明确所有电源和信号去向。

操作顺序：

1. 依据参考 PDF 放置 USB 连接器、ESD 保护器件、CH340G 和扩展连接器。
2. USB 连接器的 `D+`、`D-` 先经过 ESD 器件，再连接 CH340G。
3. 给电源引脚连接正确的 `5V`、`3V3`、`GND`。
4. CH340G 的 UART 信号使用统一网络名：`UART_RXD_F12`、`UART_TXD_D12`。
5. 扩展排针每个引脚必须有清晰的网络名，不要只写一行说明文字。
6. 检查 USB 屏蔽、ESD 接地和去耦电容是否与参考原理图一致。

完成标准：USB D+/D- 不是悬空文字；连接器所有有效引脚都有网络或明确的 No ERC 标记。

#### 页面 2：`02_FPGA_Clock_Flash.SchDoc`

目标：完成 FPGA 六个分部、配置 Flash、主时钟和全部电源去耦。

操作顺序：

1. 将 U1 的六个 Part 排列整齐，每个 Part 之间留出足够连线空间。
2. 对照参考 PDF，逐个引脚录入网络名，不要凭记忆猜测。
3. 配置 Flash 使用统一网络：`SPI_CS`、`SPI_CLK`、`SPI_MOSI`、`SPI_MISO`。
4. 主时钟输出使用 `CLK_20M`，时钟器件周围的电阻、电容按参考值放置。
5. 所有 FPGA 电源引脚按器件手册区分核心电源、IO 电源和地，例如 `1V2`、`3V3`、`GND`；不要把不同电源轨直接短接。
6. 每个电源组附近放置去耦电容；电容值和数量以参考板及器件手册为准。
7. 未使用但允许悬空的引脚放置 No ERC；禁止用 No ERC 掩盖未知连接。

完成标准：U1 各分部 Designator 都是 `U1`，Part ID 不同；Flash、时钟、电源网络均能被工程识别。

#### 页面 3：`03_USB_JTAG.SchDoc`

目标：完成 USB-UART、JTAG 控制器和 FPGA JTAG 接口。

操作顺序：

1. USB 接口与 ESD 器件靠左，控制器放中间，FPGA/JTAG 网络靠右。
2. 统一使用 `USB_D+`、`USB_D-`。
3. UART 使用 `UART_RXD_F12`、`UART_TXD_D12`。
4. JTAG 使用 `JTAG_TCK`、`JTAG_TMS`、`JTAG_TDI`、`JTAG_TDO`。
5. 按参考 PDF补齐上拉/下拉电阻、复位、启动配置和去耦电容。
6. 检查发送和接收方向：TX 必须连接对端 RX，不能 TX 对 TX。

完成标准：所有 JTAG 网络能在 FPGA 页找到同名目标；没有方向接反。

#### 页面 4：`04_UserIO.SchDoc`

目标：完成拨码开关、LED、数码管、矩阵键盘、DAC、蜂鸣器和低频时钟。

必须使用以下映射：

| 功能 | FPGA 管脚 |
|---|---|
| SW1～SW8 | A9、A10、B10、A11、A12、B12、A13、A14 |
| LED1～LED8 | B14、B15、B16、C15、C16、E13、E16、F16 |
| 数码管段选 | A4、A6、B8、E8、A7、B5、A8、C8 |
| 数码管位选 | C9、B6、A5、A3 |
| 蜂鸣器 | H11 |
| 低频时钟 | R7 |
| 键盘列 | F10、C11、D11、E11 |
| 键盘行 | E10、C10、F9、D9 |

操作顺序：

1. 每个 LED 必须串联限流电阻，阻值按参考原理图。
2. 蜂鸣器若由三极管/MOSFET 驱动，必须保留驱动器件和保护器件，不能直接接 FPGA。
3. 数码管确认共阳或共阴；段选和位选驱动极性必须与器件一致。
4. 矩阵键盘的行列不要写成一个合并标签，应分别命名，如 `KEY_ROW0_E10`、`KEY_COL0_F10`。
5. 拨码开关输入需要确定上拉或下拉，不能让 FPGA 输入悬空。
6. DAC 和低频时钟按参考 PDF 完整复制，包括电阻电容值。

完成标准：每个用户 IO 都能追踪到唯一 FPGA 管脚，且驱动电路和电气方向合理。

#### 页面 5：`05_Power.SchDoc`

目标：完成输入保护、稳压、电源滤波、反馈网络和电源指示。

操作顺序：

1. 从输入端开始按能量流向排列：输入连接器 → 保护 → 稳压器 → 电感/二极管 → 输出电容 → 负载。
2. 严格照参考 PDF填写稳压器型号、反馈电阻和电容值。
3. 统一电源网络名，例如 `VIN_5V`、`VCC_3V3`、`VCC_1V2`、`GND`。
4. 检查二极管、电解电容、LED 等有极性器件方向。
5. 检查稳压器输入/输出电容是否靠近相应引脚，并确认额定电压足够。
6. 不要把 `VIN_5V`、`VCC_3V3` 和 `VCC_1V2` 误用同名标签连接。

完成标准：从输入电源可以沿导线追踪到每条电源轨；没有不同电压网络短接。

## 五、统一编号、参数和封装

### 5.1 自动编号

1. 保存所有原理图。
2. 在 `Projects` 面板右击工程，选择 `Annotate Schematics`；部分版本位于 `Tools → Annotation → Annotate Schematics`。
3. 选择整个工程，执行 `Update Changes List`。
4. 检查列表后执行 `Accept Changes / Annotate`。
5. 确保同一个多分部 FPGA 都使用 `U1`，不要被自动编号成 U1～U6。

### 5.2 检查器件参数

逐个双击器件检查：

- Designator：R1、C1、U1 等，不重复。
- Comment：实际型号或阻容值，不能全部保留默认名称。
- Footprint：必须存在且与实物封装一致。
- 极性和 Pin 1：与数据手册一致。

### 5.3 分配封装

1. 在原理图编辑器选择 `Tools → Footprint Manager`。
2. 左侧选择器件，右侧检查当前 Footprint。
3. 优先使用项目提供的 `EG4S20BG256.PcbLib` 和其他已解包的 `.PcbLib`。
4. 找不到封装时，先核对器件完整型号，再创建或选择相同焊盘尺寸的封装。
5. 绝不能因为“看起来差不多”就使用不同引脚数量或不同间距的封装。
6. 对 EG4S20BG256，确认实际封装的焊球行列、球距、焊盘直径和 Pin 1 标记；不要继续使用当前脚本生成的离散焊盘作为最终器件。
7. 执行 `Accept Changes (Create ECO)`，再执行 ECO。

完成标准：Footprint Manager 中没有关键器件显示缺失封装。

## 六、编译原理图并完成 ERC

1. 先执行 `File → Save All`。
2. 在 `Projects` 面板右击 `EG4S20_SummerProject.PrjPcb`。
3. 选择 `Validate PCB Project`；旧版可能显示 `Compile PCB Project`。
4. 打开 `Panels → Messages` 查看结果。
5. 双击消息可跳到对应对象。

### 6.1 错误处理顺序

先处理 Error，再处理 Warning：

1. Duplicate Designators：器件编号重复，重新编号。
2. Unconnected Pin：引脚未连接；补线或确认后放 No ERC。
3. Net has only one pin：标签没有真正连接到其他器件，检查拼写和吸附点。
4. Conflicting Net Names：同一导线上出现两个不同网络名，删除错误标签。
5. Power pin not driven：检查电源输出类型，必要时放置正确的 Power Port 或 PWR Flag 类器件。
6. Missing Footprint / Could not find model：重新分配封装，不要直接忽略。

完成标准：所有 Error 为 0；每一条 Warning 都能解释原因并确认不会影响电路。

## 七、重新建立正式 PCB

现有 PCB 是草稿。最省返工的做法是重新生成一张干净 PCB。

1. 在工程中选择 `File → New → PCB`。
2. 保存为 `EG4S20_CoreBoard_Final.PcbDoc`。
3. 在 `Projects` 面板右击工程，选择 `Add Existing to Project`，确认新 PCB 已加入工程。
4. 保留旧 `EG4S20_CoreBoard.PcbDoc` 作为参考，不要立刻删除。
5. 打开任意原理图，选择 `Design → Update PCB Document EG4S20_CoreBoard_Final.PcbDoc`。
6. ECO 窗口中先点 `Validate Changes`。
7. 所有项目变为绿色后，点击 `Execute Changes`。
8. 关闭 ECO。所有器件应出现在板框外侧，并显示网络飞线。

如果 ECO 报找不到 Footprint，返回第五章修复封装；不要手工在 PCB 放一个“看起来类似”的器件绕过错误。

## 八、建立正确板框和层叠

### 8.1 板框尺寸不能猜

先从参考 PDF、实物测量或教师要求获得：板长、板宽、安装孔坐标、连接器位置和禁布区。把数值写在纸上后再画。

### 8.2 重画板框

1. 打开正式 PCB。
2. 选择 `View → Board Planning Mode`，或按 `1`。
3. 选择 `Design → Redefine Board Shape`。
4. 点击第一个角点，然后按顺序点击其他角点。
5. 矩形板应使用四个角点；最后右击自动闭合。
6. 按 `2` 返回二维布局模式。
7. 用 `Reports → Measure Primitives` 或尺寸标注工具复核长宽。

如果画成三角形，立即 `Ctrl+Z`，不要继续布局。

### 8.3 层叠建议

层数必须以课程要求和制板能力为准。EG4S20BG256 BGA 若需要真实可制造的扇出和稳定电源，通常应优先评估四层板：Top / GND / Power / Bottom。若教师明确要求两层，则按教师要求执行并确认 BGA 是否真的需要全部引出。

设置路径：`Design → Layer Stack Manager`。修改后保存并关闭窗口。

## 九、设置 PCB 设计规则

在布线前选择 `Design → Rules`。规则值必须满足 PCB 制造商能力。没有指定制造商时，可先用以下“课程草稿值”，最终制板前必须再确认：

| 项目 | 起始建议 |
|---|---|
| 普通信号线宽 | 0.20 mm |
| 普通信号间距 | 0.20 mm |
| 电源主干线宽 | 0.50～1.00 mm，按电流复核 |
| 普通过孔外径/孔径 | 0.60/0.30 mm |
| 铜到板边距离 | ≥0.30 mm |

需要检查的主要规则：

1. `Electrical → Clearance`：铜对象最小间距。
2. `Routing → Width`：最小、首选和最大线宽。
3. `Routing → Routing Via Style`：过孔尺寸。
4. `Manufacturing → Hole Size`：孔径范围。
5. `Manufacturing → Board Outline Clearance`：到板边距离。
6. `Plane → Polygon Connect Style`：铺铜与焊盘连接方式。

USB D+/D- 若要按差分阻抗设计，必须先知道板厂层叠、介质厚度和铜厚，再计算线宽/间距；不知道层叠时不要声称已经做到 90 Ω。

## 十、器件布局

### 10.1 推荐顺序

1. 安装孔和尺寸受限连接器。
2. USB 接口、扩展排针、电源输入等板边器件。
3. FPGA 放在板中心附近。
4. Flash、主时钟紧靠 FPGA 对应引脚。
5. 去耦电容紧靠每个电源引脚或电源球组。
6. 稳压器、二极管、电感、输入/输出电容组成紧凑电源回路。
7. LED、拨码开关、按键、数码管放在便于操作和观察的位置。
8. 其余电阻电容按所属功能分组放置。

### 10.2 实际操作

1. 按 `2` 进入二维模式。
2. 鼠标放在器件轮廓上，按住左键拖动。
3. 拖动时按 `Space` 旋转。
4. 所有器件本体、焊盘和丝印都必须位于板框内，连接器允许按机械要求伸出板边。
5. 使用飞线判断布局：交叉越少、路径越短通常越好。
6. 按 `3` 进入三维模式，检查连接器方向、器件重叠和板边干涉；按 `2` 返回。

### 10.3 关键布局要求

- USB ESD 器件应靠近 USB 连接器，不能放在 CH340G 后面。
- FPGA 时钟走线尽量短，远离开关电源节点。
- Flash 靠近 FPGA，SPI 走线短而直接。
- 去耦电容的电源端到芯片电源脚、地端到地过孔都应很短。
- 开关稳压器的高 di/dt 回路面积要小，反馈线远离开关节点。

布局完成前不要大规模布线。

## 十一、PCB 布线

### 11.1 布线顺序

1. 电源和地回流规划。
2. 主时钟。
3. USB D+/D-。
4. FPGA 配置 Flash。
5. JTAG、UART。
6. LED、开关、键盘、数码管等普通 IO。

### 11.2 交互布线操作

1. 选择 `Route → Interactive Routing`，快捷键通常为 `Ctrl+W`。
2. 点击一个焊盘开始布线。
3. 沿飞线方向移动，单击固定转角。
4. 点击目标焊盘完成当前网络。
5. `Shift+Space` 切换转角方式，优先使用 45°。
6. `Backspace` 撤销当前网络的最后一段。
7. 需要换层时放置过孔；换层后检查回流路径。
8. 右击一次放弃当前网络，右击第二次退出布线模式。

不要通过强行穿过焊盘、缩小间距或关闭 DRC 来“完成”布线。

### 11.3 BGA 注意事项

1. 使用正式 BGA Component，而不是 256 个互不归属的散焊盘。
2. 先制定扇出策略，再从外围球向外布线。
3. 内层球通常需要过孔扇出；过孔和线宽必须满足板厂能力。
4. 电源/地球应就近连接平面和去耦网络。
5. 若两层板无法合法扇出，停止并与教师确认层数，不能靠违反间距规则解决。

完成标准：状态栏或 PCB 面板中 `Un-Routed` 为 0；所有飞线消失。

## 十二、GND 铺铜

1. 确认已经存在名为 `GND` 的 PCB 网络。
2. 选择 `Place → Polygon Pour`。
3. 按 `Tab` 打开 Properties。
4. 设置 Layer 为目标铜层，Net 为 `GND`。
5. 沿板框内侧依次点击顶点。
6. 最后右击，Altium 会自动闭合多边形。
7. 对需要铺铜的其他信号层重复操作。
8. 修改布线后执行 `Tools → Polygon Pours → Repour All`。
9. 检查孤岛铜、窄缝和没有实际连接的地铜。

铺铜不能代替正确的 GND 网络。若 Polygon 的 Net 显示 `No Net`，必须先修复原理图和 PCB 网络同步。

---

## 十三、运行 DRC 并清零错误

1. 保存全部文档。
2. 在 PCB 编辑器选择 `Tools → Design Rule Check`。
3. 左侧确认需要的项目已启用 `Batch DRC`。
4. 点击 `Run Design Rule Check`。
5. 在 Messages 或 PCB Rules and Violations 面板中查看结果。
6. 双击每个错误定位并修复，然后重新运行 DRC。

重点错误：

- Clearance Constraint：铜间距不足。
- Short-Circuit：两个不同网络短路，必须修复。
- Un-Routed Net：还有飞线未完成。
- Width Constraint：线宽超出规则。
- Hole Size / Via Style：过孔不符合规则。
- Component Clearance：器件重叠。
- Silk to Solder Mask：丝印压到焊盘。
- Board Outline Clearance：铜或器件太靠近板边。

最终标准：DRC Error 为 0，Un-Routed 为 0。Warning 不能简单删除，必须逐条确认。

---

## 十四、最终输出文件

只有 ERC、DRC 和人工检查都通过后才生成制造文件。

### 14.1 原理图 PDF

1. 打开工程。
2. 使用 `File → Smart PDF`。
3. 选择当前工程和全部原理图页。
4. 输出到 `Outputs\PDF`。
5. 打开 PDF，逐页检查文字是否截断、器件是否在页面外。

### 14.2 BOM

1. 选择 `Reports → Bill of Materials`。
2. 输出 Excel 或 CSV。
3. 至少包含 Designator、Quantity、Comment、Manufacturer Part Number、Footprint。
4. 检查同一型号是否正确合并，关键器件是否缺少完整型号。

### 14.3 Gerber X2 和钻孔

最稳妥方式是建立 OutJob：

1. `File → New → Output Job File`。
2. 在 Fabrication Outputs 中添加 `Gerber X2`。
3. 添加 `NC Drill`。
4. 添加 `Board Stack Report` 和需要的 Drill Drawing。
5. 设置输出目录为 `Outputs\Fabrication`。
6. 点击 `Generate Content`。
7. 使用 CAM 查看器重新打开生成文件，检查板框、铜层、阻焊、丝印和钻孔是否对齐。
8. 向板厂确认其需要 Gerber X2、传统 Gerber、ODB++ 或 IPC-2581 中的哪一种，不要同时发送多个互相冲突的版本。

## 十五、提交前的人工检查清单

逐项打勾：

- [ ] 工程打开无丢失文档。
- [ ] 五张原理图标题和页码正确。
- [ ] 所有器件编号唯一，多分部 FPGA 仍为同一 U1。
- [ ] 器件型号、阻容值、极性和封装已核对。
- [ ] 所有网络标签实际连接在导线上。
- [ ] 电源轨 5V、3V3、1V2 未短接。
- [ ] 用户 IO 管脚映射与任务要求一致。
- [ ] ERC Error 为 0，Warning 已确认。
- [ ] 正式 PCB 使用正确尺寸板框，不是三角形。
- [ ] 所有器件位于板内，连接器方向正确。
- [ ] BGA 使用正式封装，不是散焊盘集合。
- [ ] Un-Routed 为 0。
- [ ] GND Polygon 已 Repour。
- [ ] DRC Error 为 0，Warning 已确认。
- [ ] 3D 视图无明显器件重叠或方向错误。
- [ ] Gerber、钻孔和板框在 CAM 查看器中对齐。
- [ ] 已生成 PDF、BOM、Gerber X2、NC Drill 和最终备份。

## 十六、遇到问题时如何判断下一步

| 现象 | 原因 | 处理 |
|---|---|---|
| 器件移不动 | 仍在其他命令或对象被锁定 | 按两次 Esc；检查 Properties 中 Locked |
| 保存提示 command active | 放置、布线、板框或脚本命令未结束 | 选 No，按两次 Esc，再保存 |
| Update PCB 找不到器件 | 未分配封装或库路径无效 | 返回 Footprint Manager 修复 |
| PCB 没有飞线 | 原理图没有真实连线或 PCB 网络未同步 | 先 Validate，再重新 Update PCB |
| 标签存在但网络不通 | 标签连接点没吸附到导线，或名称不一致 | 放大检查连接点和拼写 |
| 出现大量 Missing Model | SchLib 引用的 PcbLib/模型不可用 | 重新关联项目内 PcbLib，不能全部忽略 |
| 铺铜不连接 GND | Polygon 为 No Net 或 GND 网络名不同 | 修复网络并设置 Polygon Net=GND |
| DRC 错误太多 | 布局布线前未设置规则 | 先设置规则，再逐类处理，不要全选忽略 |
| BGA 无法两层扇出 | 层数、孔径或间距能力不足 | 停止布线，与教师确认四层板/工艺能力 |

## 十七、推荐工作节奏

每次只完成一个可检查的小目标：

1. 第 1 次：整理页面 1 和页面 2。
2. 第 2 次：整理页面 3、4、5。
3. 第 3 次：编号、参数、封装、ERC。
4. 第 4 次：重新生成正式 PCB、板框、规则。
5. 第 5 次：布局。
6. 第 6～7 次：布线和铺铜。
7. 最后：DRC、PDF、BOM、Gerber 和总检查。

每次结束前：按两次 `Esc` → `File → Save All` → 退出 Altium → 复制项目文件夹作为当天备份。
