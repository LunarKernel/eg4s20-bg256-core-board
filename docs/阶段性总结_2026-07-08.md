## 当前剩余 Warning

当前 Validate 结果没有 error，只剩以下 warning：

```text
Net SPI_CLK has no driving source (Pin U1-R11, Pin U2-6)
Net SPI_CS has no driving source (Pin U1-T3, Pin U2-1)
Net VIN_5V has no driving source (Pin J1-1, Pin J2-1, Pin U8-3)
VCC_3V3 contains IO Pin and Power Pin objects (Pin U2-3, Pin U2-7, Pin U2-8, Pin U4-5, Pin U8-2, Pin Y1-4)
```

这些 warning 当前不阻塞 PCB 同步。

建议处理方式：

```text
SPI_CLK / SPI_CS:
  FPGA 到 Flash 的信号网络，本身由 FPGA 驱动。若 Altium 仍按 pin 类型报 no driving source，
  后续可以调整相关 pin electrical type，或在确认无误后保留 warning。

VIN_5V:
  来自 USB/外部输入，原理图内没有主动驱动源是正常现象。后续可用 Power Port 或 No ERC 降低提示。

VCC_3V3:
  这是电源网络和部分器件 IO/电源脚混在一起造成的 ERC 类型提示。
  当前不是连接错误，后续可通过 pin 类型/电源符号/No ERC 精细化处理。
```

## 下一阶段任务

下一阶段进入 PCB Layout，建议不要立刻布线，先完成元件摆放。

推荐摆放顺序：

```text
1. J1 / J2
   USB 接口优先放在板边，接口朝外。

2. U1
   FPGA 放在核心区域中间，后续所有外设围绕它收敛。

3. U2
   Flash 靠近 U1 的 SPI 引脚，缩短 SPI_CS / SPI_CLK / SPI_MOSI / SPI_MISO。

4. Y1 / Y2
   晶振靠近对应芯片的时钟输入脚，时钟线尽量短。

5. U8 / U10 / FB1 / D1 / C1 / C2
   电源部分集中摆放，先确认 VIN_5V、VCC_3V3、VCC_1V2、ADC_VDDA 的方向。

6. DS1 / SW1-SW4 / BZ1 / D1
   用户交互器件放在容易操作和观察的位置。
```

摆放原则：

```text
黄色飞线越短越好。
先摆大器件和接口，再摆小器件。
先按功能块摆放，不急着拉线。
电源、时钟、USB 差分、SPI 这些网络优先减少绕线距离。
```
