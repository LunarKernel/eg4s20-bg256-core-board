### 2. 板框尺寸


后续继续布局时必须以这个板框为准，不要再使用此前遗留的三角形/临时板框。

- J1/J2 右侧接口已从越界位置整体左移，当前在 100 mm x 68 mm 板框内。

此前有一版右侧接口越过板框，已经回退并重做，不能再使用该越界布局。

## 当前风险和待确认项

1. 尚未完成完整 DRC。
   本阶段完成的是布局、规则、自动布线和实际飞线补齐。出板前必须运行 `Tools > Design Rule Check`。

2. 丝印和器件间距可能仍有提示。
   PCB 自动布线设置窗口曾提示 `no default SMDNeckDown rule exists`，这不是布线错误，但 DRC 可能仍会报丝印重叠、器件间距等非电气问题。

3. GND 连接建议后续铺铜。
   当前用短线补齐了实际 GND 飞线，但正式 PCB 建议增加 GND Polygon Pour，并重新检查孤岛、热焊盘和回流路径。

4. USB 差分线尚未按高速规则优化。
   当前布线是功能连通优先，并未严格做 USB_D+ / USB_D- 等长、阻抗和差分间距控制。若课程要求只做基础板，当前可作为草稿；若要接近可制造产品，需要单独优化 USB 区域。

5. 需要输出制造文件前再检查封装焊盘。
   生产端给出的焊盘最小 0.25 mm 需要结合封装库逐项确认，特别是 BGA、SOP、DBV、USB/JTAG 小间距器件。

## 下一步建议

1. 打开 `EG4S20_SummerProject.PrjPcb`，运行完整 DRC。
2. 处理 DRC 中真正影响制造的错误：间距、短路、未连接、孔径、板框外对象。
3. 对 GND 执行铺铜，并重新 repour / DRC。
4. 重点人工检查 USB_D+ / USB_D-、晶振、FPGA 电源附近布线。
5. 生成 Gerber X2、NC Drill、BOM 和装配截图前，再保存并提交一次。
