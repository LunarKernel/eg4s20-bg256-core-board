# Experimental Failed Scripts

These scripts are kept only for troubleshooting history.

They attempted to create or modify Altium `.SchDoc` files by direct OLE/CFB file manipulation. That approach produced invalid or visually corrupted schematic documents in Altium Designer, including blank documents, frozen loads, and misplaced objects.

Do not use these scripts for deliverables. Continue with `AltiumProject/CreateA0NativeFromSheets.PrjScr`, which uses Altium Designer's native scripting API.
